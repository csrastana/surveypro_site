## Что добавить на главную
В footer русской версии:
```html
<a href="/knowledge/">База знаний</a>
```

## Что добавить в sitemap.xml
Скопируйте блоки из `sitemap-snippet.xml` внутрь существующего `<urlset>`.

## После публикации
Проверьте 5 URL через Google Search Console → URL Inspection и запросите индексацию.
