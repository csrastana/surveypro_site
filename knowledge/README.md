### После загрузки
1. Проверьте все URL в браузере.
2. Добавьте новые URL из `sitemap-snippet.xml` в основной sitemap.xml.
3. В Google Search Console запросите индексацию новых страниц.
4. Не публикуйте одинаковый текст на внешних площадках. Для Astana Hub делайте отдельные статьи и ставьте контекстные ссылки на эти материалы.
